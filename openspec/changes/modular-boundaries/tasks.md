# Tasks

Work in `omms-feat-modular-boundaries` on `feat/modular-boundaries`, never in the main checkout. Run each focused test with `bash scripts/run-tests-isolated.sh tests/<file>.test.ts`. Run `bun run build` first when a test imports `dist/`.

A mutation step means: make the named temporary edit, run the test, see it fail and name the file, undo the edit, and run the test again to see it pass. Never commit a mutation.

No task may change user-visible behaviour. Do not remove or weaken an existing assertion. In existing tests, change only import lines and the SDK pattern.
